# Jaisimha Portfolio Website

## Overview
Build a polished, single-page editorial portfolio that immediately establishes Jaisimha as a Product Designer and Graphic Designer. The site will use a warm off-white canvas, dark ink typography, and carefully balanced coral, cobalt, and lime accents so the work feels creative without becoming cluttered.

Because no portrait or portfolio images were uploaded, all visual areas will be clearly labeled placeholders ready for Jaisimha’s real photo and project images. No client names, contact details, or project claims will be invented.

## What I’ll Build
- Sticky responsive navigation with desktop links, a mobile menu, and Contact Me action.
- High-impact introduction with a large portrait placeholder, name, role, professional summary, CTAs, experience marker, and expertise tags.
- About, understated education, and 3+ years at VMR Graphics experience sections.
- Six service presentations with distinct icons, concise descriptions, and restrained movement.
- Portfolio centerpiece with interactive category filters, varied editorial image proportions, clear placeholder labels, and project summaries.
- Featured Product Packaging case study with overview, role, deliverables, and multiple mockup placeholders.
- Skills presented as a typographic visual system without unsupported percentages.
- Four-stage design process.
- Contact area with the requested placeholders and an interactive front-end inquiry form confirmation.
- Footer with navigation and 2026 copyright.

## Visual and Interaction Direction
- **Typography:** Syne for expressive display type and Manrope for readable body text.
- **Palette:** warm paper background, near-black ink, coral primary accent, cobalt secondary accent, and restrained acid-lime highlights.
- **Layout:** editorial asymmetry, oversized type, generous whitespace, strong rules, compact labels, and a varied portfolio grid.
- **Motion:** subtle entrance transitions, image/card lift, button feedback, smooth anchor navigation, and reduced-motion support.
- **Responsive behavior:** condensed mobile header, stacked content, full-width visual work, readable type, and touch-friendly controls.

## Technical Notes
- Implement the experience as the home route with anchored sections, matching the requested single scrolling portfolio behavior.
- Use semantic design tokens in the global stylesheet and reusable React components/data structures in the page.
- Use local icon components already available in the project.
- Add complete page-specific title, description, Open Graph, and Twitter metadata.
- Keep the contact form presentation-only because no delivery address or backend was requested.
- Verify the finished page at desktop and mobile sizes, including navigation, filtering, menu behavior, and form feedback.
